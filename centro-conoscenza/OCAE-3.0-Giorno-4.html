Titolo

Progettare skill API per collegare OpenClaw ai software aziendali

Panoramica

Quarta sessione del workshop OCAE 3.0 focalizzata sulle skill software e sull'integrazione di OpenClaw con software aziendali tramite API.

Argomenti trattati

  • Ripasso tipologie di skill (logica, software, orchestratrice)
  • Skill software in dettaglio: verifica API, software aperti vs chiusi
  • Progettazione di connettori API separati dalla logica del workflow
  • Processo di creazione skill: ingressi, regole, uscite, test
  • Workflow automatici: da sequenza manuale a completamente automatizzato
  • Repository di skill: costruzione di una libreria riutilizzabile

Strumenti menzionati

OpenClaw, ChatGPT/Codex, ActiveCampaign, Zapier, Vimeo, CourseSprout, Telegram
